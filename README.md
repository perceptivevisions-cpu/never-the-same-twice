# Nobody Remembers — never the same twice

A film that assembles itself as it plays. Photographs, words and film by Jason Lindsey.
Every viewing is a new version: scene order, images, lines, flashes, weather and music entries are chosen in the moment.

## Publish on GitHub Pages
1. Upload everything in this folder to a repository (keep `index.html` at the top level, next to `assets`).
2. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`. Save.
3. After a minute it's live at `https://<username>.github.io/<repository-name>/`.

## Viewing locally
Run `python3 -m http.server` in this folder and open http://localhost:8000.

## Keys
T sliders (grain, ink, glow, text size, push-in, flicker, vignette, music level, music low end) · Esc ends the version
